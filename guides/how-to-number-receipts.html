How to number receipts

Unique numbers prevent confusion when a client asks for a copy months later.

Educational only — not tax or legal advice.

Create a receipt free →

Rules of thumb

  1. One number = one receipt.
  2. Prefer zero-padded sequences (0001, 0002…).
  3. Optional prefix: shop code, year, or “CASH-”.
  4. Write the next number down (or let the tool remember it on-device).

Common mistakes

  • Restarting at 1 every day without a date in the number
  • Editing old PDFs to “fix” a wrong number instead of issuing a corrected copy note
